# AI 첫걸음 시리즈

이 저장소는 「**AI 첫걸음 시리즈**」의 실습에 사용되는 데이터셋과 관련 자료를 제공합니다.

「AI 첫걸음 시리즈」는 **코딩과 수학의 부담 없이 시작하는 AI 시리즈**로, 인공지능의 기본 개념부터 데이터 분석과 실제 활용까지 단계적으로 학습할 수 있도록 구성되어 있습니다.
