# 8.2 함께 팔면 더 잘 팔린다

「AI 첫걸음 시리즈」 Vol. 2의 8.2절
**함께 팔면 더 잘 팔린다: 연관분석** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 식료품점의 구매 기록을 이용하여 어떤 품목들이 함께 구매되는지를 분석하는 연관분석 실습에 필요한 데이터가 포함되어 있습니다.

**Groceries** 데이터셋은 한 식료품점에서 30일 동안 수집된 실제 거래 기록으로, 총 9,835건의 거래와 169개의 품목 범주로 구성되어 있습니다. 한 거래는 한 고객이 한 번의 방문에서 함께 구매한 품목들의 목록을 의미합니다.

이 데이터는 Michael Hahsler 등이 정리하여 R의 연관분석 패키지인 `arules`를 통해 공개한 데이터로, 연관분석과 장바구니 분석의 대표적인 실습 데이터로 널리 활용되고 있습니다. 해당 데이터를 이용하여 빈발 품목 조합을 찾고, 지지도(Support), 신뢰도(Confidence), 향상도(Lift)를 바탕으로 연관규칙을 분석합니다.

- **데이터셋:** Groceries
- **출처:** R `arules` 패키지
- **분석 유형:** 연관분석(Association Analysis)
- **용도:** 교육 및 실습

## 제공 파일

- `groceries_long.csv` — `TransactionID`와 `Item` 두 열로 구성된 원시 거래 형태의 데이터
- `groceries_onehot.xlsx` — Orange에서 연관분석을 바로 수행할 수 있도록 거래별 품목을 열로 변환한 데이터

`groceries_onehot.xlsx`에서는 해당 거래에서 구매한 품목을 `1`로 표시하고, 구매하지 않은 품목은 빈칸으로 두었습니다. Orange의 [File] 위젯에서 불러온 뒤 `TransactionID`의 Role을 **Meta**로 변경하여 사용합니다.

※ `groceries_long.csv`는 원시 거래 데이터를 연관분석용 형태로 직접 변환하는 추가 실습에 사용됩니다.
