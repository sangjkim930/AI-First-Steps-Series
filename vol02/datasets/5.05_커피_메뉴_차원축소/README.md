# 5.5 커피 메뉴 데이터 실습

「AI 첫걸음 시리즈」 Vol. 2의 5.5절
**커피 메뉴 데이터를 이용한 차원축소 실습**에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 10개의 커피 메뉴와 각 메뉴의 특성을 이용하여 데이터의 구조를 시각적으로 탐색하는 실습에 필요한 데이터가 포함되어 있습니다.

각 행은 하나의 커피 메뉴를 나타내며, 각 메뉴의 특성을 수치로 표현한 데이터를 이용하여 **PCA(주성분분석)**와 **t-SNE**를 적용하고, 고차원 데이터가 저차원 공간에서 어떻게 표현되는지 비교합니다.

* **데이터 구성:** 교재 실습용으로 별도 구성
* **분석 유형:** 차원축소(Dimensionality Reduction) — PCA, t-SNE
* **용도:** 교육 및 실습

## 제공 파일

* `coffee_menu.xlsx` — 10개의 커피 메뉴와 각 메뉴의 특성을 담은 PCA 및 t-SNE 실습 데이터
