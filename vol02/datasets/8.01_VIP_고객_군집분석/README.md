# 8.1 VIP 고객을 찾아라

「AI 첫걸음 시리즈」 Vol. 2의 8.1절
**VIP 고객을 찾아라: 군집분석** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 쇼핑몰 고객의 특성과 소비 성향을 이용하여 비슷한 고객들을 여러 집단으로 분류하는 군집분석 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 데이터는 Kaggle의 **Mall Customer Segmentation Data**에서 다운로드한 공개 데이터셋입니다. 쇼핑몰 멤버십 카드 가입 고객의 기본 정보와 소비 성향을 담고 있으며, 고객 세분화(Customer Segmentation)를 학습하기에 적합한 데이터입니다.

특히 `Spending Score`는 고객의 구매 행동을 바탕으로 쇼핑몰이 1점에서 100점 사이로 부여한 지표로, 값이 높을수록 지출 성향이 큰 고객을 의미합니다.

* **데이터셋:** Mall Customer Segmentation Data
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python
* **분석 유형:** 군집분석(Clustering)
* **용도:** 교육 및 실습

## 제공 파일

* `mall_customers.csv` — 고객의 특성과 소비 성향을 이용하여 고객 집단을 분류하는 군집분석 실습 데이터
