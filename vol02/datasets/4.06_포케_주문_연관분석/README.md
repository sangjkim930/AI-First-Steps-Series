# 4.6 포케 주문 연관분석

「AI 첫걸음 시리즈」 Vol. 2의 4.6절
**포케 주문 데이터를 이용한 연관분석 실습**에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 포케 가게의 주문 패턴을 분석하기 위한 소규모 거래 데이터가 포함되어 있습니다.

데이터는 총 20건의 주문으로 구성되어 있으며, 각 열은 `Poke`, `Grill`, `Bowl`, `Salad`의 주문 여부를 나타냅니다. 해당 메뉴를 주문한 경우 `1`로 표시하고, 주문하지 않은 경우는 빈칸으로 구성되어 있습니다.

이 데이터를 이용하여 어떤 메뉴들이 함께 주문되는지를 살펴보고, 연관분석의 기본 원리를 실습합니다.

* **데이터 구성:** 교재 실습용으로 별도 구성
* **분석 유형:** 연관분석(Association Analysis)
* **용도:** 교육 및 실습

## 제공 파일

* `poke_orders.xlsx` — 20건의 포케 가게 주문 기록을 이용하여 메뉴 간 연관관계를 분석하기 위한 실습 데이터
