# 9.1 기업은 고객을 어떻게 분류할까?

「AI 첫걸음 시리즈」 Vol. 2의 9.1절
**기업은 고객을 어떻게 분류할까?** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 신용카드 고객의 이용 특성을 바탕으로 비슷한 고객들을 여러 집단으로 분류하는 군집분석 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 **CC General** 데이터셋은 Kaggle에서 **Credit Card Dataset for Clustering**이라는 이름으로 제공되는 공개 데이터셋입니다. `BALANCE`, `PURCHASES`, `CASH_ADVANCE`, `CREDIT_LIMIT` 등 신용카드 고객의 다양한 이용 특성이 포함되어 있어 고객 세분화(Customer Segmentation)와 군집분석을 실습하는 데 활용할 수 있습니다.

Kaggle 데이터 페이지에는 각 변수의 의미도 함께 설명되어 있으므로, 실습 중 변수의 정의를 확인할 때 참고할 수 있습니다.

* **데이터셋:** CC General (Credit Card Dataset for Clustering)
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/arjunbhasin2013/ccdata
* **분석 유형:** 군집분석(Clustering)
* **용도:** 교육 및 실습

## 제공 파일

* `CC GENERAL.csv` — 신용카드 고객의 이용 특성을 이용하여 고객 집단을 분류하는 군집분석 실습 데이터

※ 이 파일은 Kaggle에서 제공되는 원본 데이터 파일입니다. 원본 데이터와 변수에 대한 자세한 설명은 위의 Kaggle 페이지에서도 확인할 수 있습니다.
