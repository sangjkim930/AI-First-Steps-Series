# 3.6 군집분석 기초

「AI 첫걸음 시리즈」 Vol. 2의 3.6절  
**군집분석 기초 실습**에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 군집분석의 기본 원리를 이해하기 위한 소규모 고객 데이터가 포함되어 있습니다.

데이터는 고객을 식별하는 메타(Meta) 변수인 `Customer`와 두 개의 수치형(Numeric) 변수인 `X`, `Y`로 구성되어 있습니다. 간단한 데이터를 이용하여 데이터 사이의 거리에 따라 군집이 형성되는 과정을 살펴봅니다.

- **데이터 구성:** 교재 실습용으로 별도 구성
- **분석 유형:** 군집분석(Clustering)
- **용도:** 교육 및 실습

## 제공 파일

- `clustering_xy.xlsx` — 고객별 `X`, `Y` 값을 이용하여 군집분석의 기본 원리를 살펴보기 위한 실습 데이터
