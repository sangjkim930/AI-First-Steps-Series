# 8.4 스팸을 걸러내는 AI

「AI 첫걸음 시리즈」 Vol. 2의 8.4절
**스팸을 걸러내는 AI: 텍스트 마이닝** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 SMS 문자 메시지를 이용한 텍스트 마이닝 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 데이터셋은 총 **5,572건의 SMS 문자 메시지**로 구성되어 있으며, 각 메시지는 스팸(`spam`) 또는 정상 메시지인 햄(`ham`)으로 구분되어 있습니다. 스팸 메시지에는 광고, 당첨 알림, 무료 혜택 등의 내용이 포함되어 있으며, 햄 메시지는 일상적인 대화나 업무 관련 메시지로 구성되어 있습니다.

원본 데이터는 Kaggle의 **Spam Text Message Classification** 데이터셋에서 다운로드할 수 있으며, 교재 실습의 편의를 위해 Excel 형식으로 정리한 파일을 이 폴더에도 제공합니다.

* **데이터셋:** Spam Text Message Classification
* **출처:** Kaggle
* **Kaggle 주소:** ㄴhttps://www.kaggle.com/datasets/team-ai/spam-text-message-classificationㅡㄴ
* **분석 유형:** 텍스트 마이닝(Text Mining)
* **용도:** 교육 및 실습

## 제공 파일

* `sms_spam.xlsx` — 5,572건의 SMS 메시지와 `spam`/`ham` 구분 정보를 담은 텍스트 마이닝 실습 데이터
