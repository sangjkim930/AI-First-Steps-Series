## 파일 안내

실습자료는 다음 원칙에 따라 제공합니다.

* 교재에서 직접 구성하거나 가공한 데이터는 실습하기 편한 형태로 제공합니다.
* Kaggle, 공공데이터포털, UCI Machine Learning Repository 등 외부에서 제공되는 데이터는 각 실습 폴더의 `README.md`에 원본 출처를 표시합니다.
* 파일 크기나 라이선스 등의 이유로 GitHub에서 직접 제공하기 어려운 데이터는 다운로드 경로만 안내할 수 있습니다.
* Orange에 기본적으로 포함된 데이터셋은 별도의 데이터 파일을 제공하지 않을 수 있습니다.
