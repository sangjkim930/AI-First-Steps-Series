# 6.6 BBC 뉴스 워드클라우드

「AI 첫걸음 시리즈」 Vol. 2의 6.6절
**BBC 뉴스 데이터를 이용한 텍스트 마이닝 실습**에 대한 안내입니다.

## 데이터 안내

6.6.3절에서는 Orange에 내장된 **BBC 뉴스 데이터셋**을 이용하여 워드 클라우드(Word Cloud)를 생성합니다.

BBC 뉴스 데이터셋은 별도의 파일을 다운로드하지 않고 Orange에서 직접 불러올 수 있습니다. 텍스트에 등장하는 단어의 빈도를 분석하고, 자주 등장하는 단어를 크게 표시하여 뉴스 문서의 주요 내용을 시각적으로 탐색합니다.

* **데이터셋:** BBC News
* **데이터 제공:** Orange 내장 데이터
* **분석 유형:** 텍스트 마이닝(Text Mining), 워드 클라우드(Word Cloud)
* **용도:** 교육 및 실습

## 제공 파일

별도의 데이터 파일은 제공하지 않습니다. Orange에서 BBC 뉴스 데이터셋을 직접 불러와 실습합니다.

※ 실습에는 Orange의 **Text Mining 애드온**이 필요합니다. [Text Mining] 관련 위젯이 보이지 않는 경우에는 교재의 부록 **「Orange Text Mining 애드온 설치와 문제 해결」**을 참고하세요.
