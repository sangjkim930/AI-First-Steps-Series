# 8.3 숨은 차원을 찾아라

「AI 첫걸음 시리즈」 Vol. 2의 8.3절
**숨은 차원을 찾아라: PCA** 실습에 사용되는 데이터입니다.

## 데이터 다운로드

데이터 파일의 용량이 크기 때문에 이 GitHub 저장소에서는 직접 제공하지 않습니다.

공공데이터포털에서 **'국민건강보험공단 건강검진정보'**를 검색하여 2023년 데이터를 다운로드합니다.

- **사용 파일:** `국민건강보험공단_건강검진정보_2023.CSV`
- **출처:** 국민건강보험공단 / 공공데이터포털
- **데이터 페이지:** https://data.edmgr.kr/dataView.do?id=www-data-go-kr-data-filedata-15007122

운영체제나 프로그램에 따라 CSV 파일의 한글 인코딩이 올바르게 표시되지 않는 경우에는 Excel에서 파일을 연 뒤 `.xlsx` 형식으로 다시 저장하여 Orange에서 불러올 수 있습니다.
