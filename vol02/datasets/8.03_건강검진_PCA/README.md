# 8.3 숨은 차원을 찾아라

「AI 첫걸음 시리즈」 Vol. 2의 8.3절
**숨은 차원을 찾아라: PCA** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 국민건강보험공단의 건강검진정보를 이용하여 주성분분석(PCA)을 실습하기 위한 데이터가 포함되어 있습니다.

원본 데이터는 2023년 일반건강검진을 받은 가입자 가운데 표본으로 추출된 약 100만 명의 건강검진 정보를 담고 있습니다. 신장, 체중, 허리둘레, 혈압, 공복혈당, 콜레스테롤, 혈색소, 간 기능 수치 등 다양한 건강검진 항목으로 구성되어 있습니다.

이번 실습에서는 이 가운데 PCA에 활용하기 적합한 수치형 검진 항목을 중심으로 분석합니다. 여러 건강지표에 포함된 정보를 소수의 주성분으로 축약하고, 변수들 사이에 숨어 있는 구조를 살펴봅니다.

* **데이터셋:** 국민건강보험공단 건강검진정보
* **데이터 기준:** 2023년
* **출처:** 국민건강보험공단 / 공공데이터포털
* **분석 유형:** 주성분분석(PCA, Principal Component Analysis)
* **용도:** 교육 및 실습

## 제공 파일

* `nhis_health_check_2023.xlsx` — 2023년 건강검진정보를 Orange에서 불러와 PCA를 실습하기 위한 데이터

CSV 원본은 운영체제나 프로그램에 따라 한글 인코딩이 올바르게 표시되지 않을 수 있어, 교재 실습에서는 Excel 형식의 파일을 사용합니다.
