# 10.8 투자 상품 가입 예측

「AI 첫걸음 시리즈」 Vol. 1의 10.8절
**투자 상품 가입 예측: S자 곡선의 마법** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 고객의 저축 잔고를 이용하여 투자 상품 가입 여부를 예측하는 로지스틱 회귀 실습에 필요한 데이터가 포함되어 있습니다.

`Bank_Investment.csv`는 로지스틱 회귀 모델을 학습하고 평가하는 데 사용하며, `Bank_Investment_new.csv`는 학습된 모델을 이용하여 새로운 고객의 투자 상품 가입 여부를 예측하는 데 사용합니다.

* **데이터 구성:** 교재 실습용으로 별도 구성
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습

## 주요 변수

* **메타(Meta):** `Client_ID` — 고객 일련번호
* **특성(Feature):** `Savings` — 저축 잔고
* **타겟(Target):** `Investment` — 투자 상품 가입 여부

## 제공 파일

* `Bank_Investment.csv` — 로지스틱 회귀 모델의 학습 및 평가에 사용하는 데이터
* `Bank_Investment_new.csv` — 학습된 모델을 이용하여 새로운 고객의 투자 상품 가입 여부를 예측하기 위해 구성한 데이터

※ 두 파일 모두 교재의 로지스틱 회귀 및 새로운 데이터 예측 실습을 위해 구성한 데이터입니다.
