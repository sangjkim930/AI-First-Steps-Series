**스팸 메일 분류: 나이브 베이즈의 활약** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 이메일의 여러 특성을 이용하여 스팸 메일 여부를 분류하는 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 `spambase.csv`는 Kaggle의 **Spambase** 데이터셋에서 다운로드한 파일이며, 교재 실습의 편의를 위해 동일한 파일을 이 폴더에도 제공합니다.

* **데이터셋:** Spambase
* **파일명:** `spambase.csv`
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/somesh24/spambase
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습
