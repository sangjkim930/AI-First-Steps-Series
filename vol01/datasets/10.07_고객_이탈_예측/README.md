# 10.7 고객 이탈 예측

「AI 첫걸음 시리즈」 Vol. 1의 10.7절
**고객 이탈 예측: 통신사의 고객 사랑법** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 고객의 여러 특성을 이용하여 향후 이탈 여부를 예측하는 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 `Churn_Modelling.csv`는 Kaggle의 **Churn Modeling Dataset**에서 다운로드한 파일입니다. 또한 학습된 모델을 이용하여 새로운 고객의 이탈 여부를 예측하는 실습을 위해 `Churn_Modelling_new.csv`도 함께 제공합니다.

* **데이터셋:** Churn Modeling Dataset
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/shivan118/churn-modeling-dataset
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습

## 제공 파일

* `Churn_Modelling.csv` — Kaggle에서 다운로드한 모델 학습 및 평가용 데이터
* `Churn_Modelling_new.csv` — 학습된 모델을 이용하여 새로운 고객의 이탈 여부를 예측하기 위해 별도로 구성한 데이터

※ `Churn_Modelling_new.csv`는 교재의 예측 실습을 위해 별도로 구성한 데이터입니다.
