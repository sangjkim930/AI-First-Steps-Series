# 10.1 아이리스 분류

「AI 첫걸음 시리즈」 Vol. 1의 10.1절
**아이리스 분류: AI 역사 속 명작** 실습에 사용되는 데이터입니다.

## 데이터 안내

아이리스(Iris) 데이터셋은 머신러닝의 대표적인 분류 데이터셋으로, Orange에 기본적으로 내장되어 있습니다. 따라서 모델 학습에 사용할 원본 데이터는 별도로 다운로드할 필요 없이 Orange에서 바로 불러올 수 있습니다.

이 폴더에는 학습된 모델을 이용하여 새로운 아이리스 꽃의 품종을 예측하는 실습에 필요한 데이터를 제공합니다.

* **데이터셋:** Iris
* **원본 데이터:** Orange에 기본 내장
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습

## 제공 파일

* `iris_new_data.csv` — 학습된 모델을 이용하여 새로운 아이리스 꽃의 품종을 예측하기 위해 별도로 구성한 데이터

※ 원본 Iris 데이터셋은 Orange에서 직접 불러오며, `iris_new_data.csv`는 교재의 새로운 데이터 예측 실습을 위해 별도로 구성한 파일입니다.
