# 10.3 과일 구별

「AI 첫걸음 시리즈」 Vol. 1의 10.3절
**과일 구별: 시장에서 쓰는 AI 눈** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 오렌지(Orange)와 자몽(Grapefruit)의 여러 특성을 이용하여 두 과일을 구별하는 분류 실습에 필요한 데이터셋이 포함되어 있습니다.

실습에 사용되는 데이터는 Kaggle의 **Oranges vs. Grapefruit** 데이터셋에서 다운로드한 파일입니다. 교재에서는 직접 다운로드하는 방법도 안내하고 있으며, 실습의 편의를 위해 동일한 파일을 이 폴더에도 제공합니다.

* **데이터셋:** Oranges vs. Grapefruit
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/joshmcadams/oranges-vs-grapefruit
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습
