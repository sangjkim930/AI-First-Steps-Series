# 10.9 의료비 예측

「AI 첫걸음 시리즈」 Vol. 1의 10.9절
**의료비 예측: 병원비 미리 계산기** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 나이, BMI, 흡연 여부 등 개인의 특성을 이용하여 의료비를 예측하는 회귀분석 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 데이터는 Kaggle의 **Medical Cost Personal Dataset**에서 다운로드한 파일입니다. 교재에서는 직접 데이터를 다운로드하는 방법도 안내하며, 실습의 편의를 위해 동일한 파일을 이 폴더에도 제공합니다.

* **데이터셋:** Medical Cost Personal Dataset
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/mirichoi0218/insurance
* **분석 유형:** 회귀(Regression)
* **용도:** 교육 및 실습

## 제공 파일

* `insurance.csv` — 개인의 특성을 이용하여 의료비를 예측하는 모델의 학습 및 평가에 사용하는 데이터
