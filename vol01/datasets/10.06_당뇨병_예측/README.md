# 10.6 당뇨병 예측

「AI 첫걸음 시리즈」 Vol. 1의 10.6절
**당뇨병 예측: 건강 관리 도우미** 실습에 사용되는 데이터입니다.

## 데이터 안내

이 폴더에는 환자의 여러 건강 관련 정보를 이용하여 당뇨병 여부를 예측하는 실습에 필요한 데이터가 포함되어 있습니다.

실습에 사용하는 `diabetes.csv`는 Kaggle의 **Pima Indians Diabetes Database**에서 다운로드한 파일입니다. 또한 학습된 모델을 이용하여 새로운 환자의 당뇨병 여부를 예측하는 실습을 위해 `diabetes_new.csv`도 함께 제공합니다.

* **데이터셋:** Pima Indians Diabetes Database
* **출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/mragpavank/diabetes
* **분석 유형:** 분류(Classification)
* **용도:** 교육 및 실습

## 제공 파일

* `diabetes.csv` — Kaggle에서 다운로드한 모델 학습 및 평가용 데이터
* `diabetes_new.csv` — 학습된 모델을 이용하여 새로운 환자의 당뇨병 여부를 예측하기 위해 별도로 구성한 데이터

※ `diabetes_new.csv`는 교재의 예측 실습을 위해 별도로 구성한 데이터입니다.
