## 데이터 안내

이번 프로젝트에서는 와인의 종류와 여러 화학적 특성을 이용하여 와인의 품질 점수를 예측합니다.

실습에 사용하는 `winequalityN.csv`는 Kaggle의 **Wine Quality** 데이터셋에서 다운로드할 수 있습니다. 이 파일은 이 GitHub 저장소에서 직접 제공하지 않으므로, 아래 Kaggle 페이지에서 다운로드하여 사용합니다.

* **데이터셋:** Wine Quality
* **실습 파일 출처:** Kaggle
* **Kaggle 주소:** https://www.kaggle.com/datasets/rajyellow46/wine-quality
* **원 데이터 출처:** UCI Machine Learning Repository – Wine Quality
* **UCI 주소:** https://archive.ics.uci.edu/dataset/186/wine%2Bquality
* **분석 유형:** 회귀(Regression)
* **용도:** 교육 및 실습

## 사용할 파일

* `winequalityN.csv` — 와인의 여러 특성을 이용하여 품질 점수를 예측하는 모델의 학습 및 평가에 사용하는 데이터

Kaggle에서 데이터셋을 다운로드한 후 압축을 해제하고, 포함된 `winequalityN.csv` 파일을 Orange에서 불러와 사용합니다.
